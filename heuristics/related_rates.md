# Related Rates

## Pattern Recognition
- Quantities changing with respect to TIME
- Keywords: "rate of change", "how fast", "increasing/decreasing"
- Given: some rates (dx/dt, dy/dt)
- Find: another rate

## Solving Template

1. **Draw a diagram** (if geometric)
2. **Identify variables** that change with time
3. **Write the relationship** between variables (equation)
4. **Differentiate implicitly** with respect to t
5. **Substitute known values** at the specific instant
6. **Solve** for the unknown rate

## Key Technique
When differentiating, apply chain rule:
- d/dt[x²] = 2x · dx/dt
- d/dt[xy] = x · dy/dt + y · dx/dt (product rule)
- d/dt[sin(x)] = cos(x) · dx/dt

## Common Relationships
| Situation | Equation |
|-----------|----------|
| Pythagorean | x² + y² = z² |
| Similar triangles | x/y = a/b |
| Circle | x² + y² = r² |
| Cone volume | V = (1/3)πr²h |
| Sphere volume | V = (4/3)πr³ |

## Common Mistakes
- Substituting values BEFORE differentiating
- Forgetting chain rule (missing dx/dt terms)
- Sign errors (negative for decreasing quantities)
- Using wrong instant in time

## Checklist
- [ ] All rates have units (e.g., m/s, ft/min)
- [ ] Differentiated BEFORE substituting
- [ ] Used correct sign for decreasing quantities
- [ ] Answer has correct units
