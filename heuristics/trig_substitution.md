# Trigonometric Substitution

## Pattern Recognition
- √(a² - x²) → use x = a·sin(θ)
- √(a² + x²) → use x = a·tan(θ)
- √(x² - a²) → use x = a·sec(θ)

## Solving Template
1. Identify the form and choose substitution
2. Compute dx in terms of dθ
3. Substitute and simplify the square root
4. Integrate in terms of θ
5. Draw a reference triangle to convert back to x
6. Add +C

## Common Mistakes
- Wrong substitution for the form
- Forgetting to change dx
- Errors converting back to x (use triangle!)
