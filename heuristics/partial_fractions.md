# Partial Fractions

## Pattern Recognition
- Rational function (polynomial / polynomial)
- Degree of numerator < degree of denominator
- Denominator can be factored

## Solving Template
1. Factor the denominator completely
2. Set up partial fraction decomposition:
   - Linear factor (x-a) → A/(x-a)
   - Repeated linear (x-a)² → A/(x-a) + B/(x-a)²
   - Quadratic (x²+bx+c) → (Ax+B)/(x²+bx+c)
3. Multiply both sides by denominator
4. Solve for constants (plug in convenient x values)
5. Integrate each fraction separately
6. Combine and add +C

## Common Mistakes
- Not doing polynomial long division first when degree(num) ≥ degree(denom)
- Missing repeated factors
- Algebra errors when solving for constants
