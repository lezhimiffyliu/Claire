# Double Integrals

## Pattern Recognition
- Integrate over a 2D region
- ∬ f(x,y) dA
- Region may be described by curves or inequalities

## Solving Template
1. Sketch the region of integration
2. Determine order of integration (dydx or dxdy)
3. Find limits:
   - Outer: constants
   - Inner: functions of outer variable
4. Set up the iterated integral
5. Evaluate inner integral first (treat outer variable as constant)
6. Evaluate outer integral

## Common Mistakes
- Wrong limits of integration
- Not sketching the region first
- Integrating in wrong order for the given limits
